# Pakistan Legal RAG Assistant

A production-quality Retrieval-Augmented Generation (RAG) assistant for answering questions from Pakistani legal documents with source citations.

## Project Objective

The goal of this project is to build a RAG system that retrieves relevant information from Pakistani legal documents and generates answers grounded only in the retrieved context.

## Initial Legal Corpus

- Pakistan Penal Code, 1860

## Planned Technologies

- Python
- LangChain
- OpenAI LLM
- OpenAI Embeddings
- Qdrant
- Streamlit

## Project Structure

- `app/` - Streamlit application
- `src/` - RAG pipeline code
- `data/` - Legal documents and processed data
- `notebooks/` - Experiments and analysis
- `reports/` - Project reports
- `tests/` - Testing
